
# SonicGesture

Control your system volume using hand gestures in real time with Python, OpenCV, and MediaPipe.

## Features

- Real-time hand tracking using a webcam.
- Detects thumb and index finger positions.
- Adjusts system volume based on finger distance.
- Displays a visual volume bar and percentage.
- Shows real-time FPS.

## Technologies Used

- Python 3.11
- OpenCV
- MediaPipe
- NumPy
- Pycaw
